# -Coffee-Sales-Analysis-Excel-Dashboard

## 📌 Project Overview

  This project is an Excel-based Coffee Sales Analysis Dashboard created to analyze sales performance, customer/order     
  activity, product performance, store locations, and ordering patterns across different hours and weekdays.


## 🛠️ Tools & Skills Used

- Microsoft Excel

- Pivot Tables

- Pivot Charts

- Slicers

- Data aggregation

- KPI cards

- Sorting & filtering

- Percentage analysis

- Sales & order analysis

- Dashboard design and visualization


## 🚀 How to Use

- Download/open the Excel workbook.

- Use the slicers to filter the dashboard by Month and Day Name.

- Explore KPI cards and charts.

- Use the dashboard to identify sales, product, store, hourly, weekday, and size patterns.

Practice Project | Excel Dashboard | Sales Analytics
